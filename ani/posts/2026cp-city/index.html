比賽前一兩個星期

成大微積分跟線性代數都延後段考
所以我只好繼續讀??? 直接壓縮我的讀資訊的時間
雖然讀不讀對這次結果影響不大\

到前一個星期 也就是萬聖節
我去考了 APCS 高級 抱著雄心壯志去破台 啊應該真的破台了
不知道為什麼全考 DP 什麼南區賽練習 因此我覺得我手感不錯
南區應該不至於像校內複選一樣打那麼差

然後這幾天我迷上了看動畫馬拉松 平均一天看了 1.25 季動畫吧
發覺自己過得有點爽\

賽前一天

上完微積分(其實沒在認真上) 後被抓去刷 atcoder
刷得很累還有一題卡很久 + 一題 bottom-up 寫多了不會 top-down 所以燒雞的題目
其他還好 覺得手感不錯 但雖然我 wpm 很高可是不知道為什麼寫 code 比 DB 還慢了一些

晚上看完動畫之後(是的我又在看全集馬拉松了) 就開了直播刷 cses dp
中間燒雞了不少題 所以後來用讀的ww 但是沒有刷 graph 可惡

比賽當天

賽前

大概 6:50 起床
吃個早餐整理一下書包 7:10 出門
因為南女離我家好近 所以我決定慢跑過去
花了大概 7 分鐘就到了 好爽 而且運動完特別有精神 讚欸
後來等好久 早就知道晚點去了 我的號碼貼紙還因為我流汗黏不住w
打了幾場排球(其實是皮卡丘打排球) 就開始發呆

賽中

花了幾分鐘測機 本來想測 TLE 但沒有測到
還發現 submit 有 cd 怕機房撐不住嗎
接下來好像沒有什麼好說的 就按照我寫的順序來吧
第一題 LIS 典題 3 分鐘寫完但是 lower_bound 寫成 upper_bound 所以多花一分鐘改掉並測試
後來討論發現教授沒測非嚴格遞增的測資 好爛喔

再來第二題發現一樣是典題但是我那題 cses 上沒寫過就先跳過了
第三題想了一下發現是 bitmask, 但是我想了一陣子感覺有點錯就先跳過 沒想到一樣是 graph 典題啊 該刷 cses 了
再來是第四題 雖然是題目跟範圍都是經典區間第 k 小很難實作 但是注意到南區賽測資很小 所以暴力一下就過了 好爽
第五題也很簡單但我沒看清楚題目稍微卡了一下下 然後有一次我很自信的 submit 結果吃 CE 因為這題我噴了兩個還三個罰時
後來花了很久的時間在寫第六題 還好最後有刻出來 這樣四題好像花了一個小時左右\

接著看了第七題發現是 dp 但狀態好多 寫了一下下就跳題了
再來寫了第八題 發現是範圍超小背包 dp 就快速寫掉了
再來因為 10 11 12 都好多字不是很想讀所以就先放著 看到時間跟我剩下的題目數量發現我好像有點燒雞了 所以就先回去寫第三題
第三題在經過一番輸出 debug 之後發現我會寫了 耶
再來繼續看第九題 要找的數字可以到第 1e18 個是什麼鬼 信教授也找不出來 所以範圍在 5e6 簡單剪枝爆搜就過了 爽到
後來回去寫第二題 結果沒有很難 可惡 看過題目沒有寫過變成一種心理壓力了\

到現在我就剩四題了 於是我就看了 10 發現不會寫而且一臉 NP 問題所以果斷決定跳過
看到第 11 又發現是枚舉 並且發現我有學到 $3^n$ 的 subset 枚舉就很爽 趕快開始寫
結果一路 debug 到比賽結束… 沒有看到第 12 題
然後還發現不知道為什麼我的 code 本地執行成功 judge CE 超怪啊 雖然我的 code 有 goto 但應該也不至於啊

原本聽說南女電腦編譯要 10 秒但這次一兩秒就好了 有進步欸
可是那個鍵盤有夠難打的 而且輸入法超怪 我在 codeblocks 上會一直切成中文或是全形 我都要花好幾秒才可以恢復 我沒打好一定是這個的原因
還有中途看到有人起來出去了嚇死 結果是一個小時沒有更新網站被強製登出就無法登入了 什麼爛設計
整體來說 題目大部分還行 但測資不行 然後環境好爛喔 windows 扣 100 分 所以可以把資訊跟地科的比賽場地調換嗎
這樣數學物理資訊一起 化學生物地科一起也比較合理一點(?)

賽後

DB 出來說他 11 題 好扯喔
我跟 asdfg 在討論是直接看 zerojudge scoreboard 還是算題數跟看罰時 因為我們會根據這個的不同有名次不同
結果最後是數題數比罰時 可惡
為什麼 DB 第七題 greedy 可以過啦 早就知道我也寫 greedy 了
沒有注意到第 12 題是大水題 前面 10 11 題題目都太長了我看得有夠累而且時間也不多就想說不看了 結果是水題哀哀
而且第 11 題我少注意到一個東西結果就沒 debug 出來了 真可惜
因為 12 題特別多也沒有提早破台之類的 完全不知道有沒有其他學校的突然寫出一堆 就有點提心吊膽
後來出去打排球 籃球 被教官趕走之後換地方打排球 運動量充足 回到禮堂繼續打排球 爽欸

教授講評看起來挺不爽 不知道是看到前面全部都是我們還是其他人寫太爛了
接著名次的公布是資訊先 好緊張啊
佳作沒有 第六沒有 喔耶全國穩了 結果第三名 欸可惡 差 asdfg 罰時啊
沒關係有全國賽可以玩 更好的是有公假可以請

整個比賽結束後

跟很多人跑去國中找資優班+普班老師
看到他們的地科講義: 水文 地質與天文 ??????
水文到底是什麼不精確的形容詞啊 至少也寫水圈吧 難怪之前有學弟跟我說地科範圍包含水文:<
然後我就不小心嗆到老師了
後來去找班導 然後班導都特別會聊天嗎 我被硬控快 2 個小時 19:30 才出校門

btw 前幾天看到孤獨搖滾要出虹夏劇場 所以就給她一個版面
